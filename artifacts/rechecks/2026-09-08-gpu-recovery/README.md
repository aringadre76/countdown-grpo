# GPU recovery evidence

This directory is the saved 2026-09-08 ROCm rerun. It is kept separate from
the earlier CPU evidence and was generated from the commands in
[`docs/reproduction.md`](../../../docs/reproduction.md).

- `environment-rocm-torch.json`: observed WSL, package, HSA, Torch, and
  process probes.
- `qwen-preflight-eager.json`: Qwen3.5 forward, generation, live LoRA target,
  backward, and adapter-update checks on `cuda:0`.
- `base-eager.jsonl` and `base-eager.summary.json`: untouched-base bounded
  baseline (40 source-held-out and 40 fresh records).
- `grpo-smoke-eager-s42/`: one-step integration smoke.
- `grpo-diagnostic-eager-s42/`: 25-step diagnostic, all saved telemetry, run
  configuration, trainer metrics, and GPU memory.
- `adapter-eager-diagnostic.jsonl` and its summary: paired evaluation of the
  diagnostic adapter.
- `report.md` and `summary.svg`: evidence-only report and exact-solve plot
  generated by `countdown_grpo.report`.

The diagnostic completed on the RX 7900 XTX but had one positive completion and
24 all-zero steps. The adapter's one source success and zero fresh successes do
not establish arithmetic-search improvement, so the protocol did not authorize
a longer run.

The gated train/dev follow-up is recorded separately under
[`../2026-09-08-gpu-followup/`](../2026-09-08-gpu-followup/).
